# Security policy

## Supported versions

Only the latest published release of `@mlt-a/jspdf-toolkit` receives security fixes.

## Reporting a vulnerability

Please do not open a public issue for a security problem.

Report it privately through GitHub: open the [Security tab](https://github.com/mlt-a/jspdf-toolkit/security) and choose
**Report a vulnerability**, or go straight to the
[report form](https://github.com/mlt-a/jspdf-toolkit/security/advisories/new).

A useful report gives:

- the affected version;
- a minimal snippet or document that reproduces the problem;
- what an attacker could do with it.

The discussion stays on the private advisory until a fix is released. The advisory is then published and credits you,
unless you prefer otherwise.

## Scope

This policy covers the code of this repository. A vulnerability in jsPDF itself belongs
[upstream](https://github.com/parallax/jsPDF/security).
